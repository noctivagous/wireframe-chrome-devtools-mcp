Tool Instructions

1. DAW UI Challenge

Goal: Build a DAW shell with header, track sidebar, main track view, and transport footer.

  • Call layout_live_editing with recipe "app_shell".
  • Target: #daw-playground.
  • Params: headerHeight: "48px", sidebarWidth: "200px", showFooter: true.

2. Keyboard Challenge

Goal: Create a piano keyboard using different CSS methods.

  • Method A (Flex): Use layout_parametric_stack with direction: "row".
  • Method B (Grid): Use layout_parametric_grid with 12 columns for an octave.
  • Method C (Absolute): Use overlay_grid to position black keys on top of white keys.
  • Target: #keyboard-playground.

3. Recipes & Components

Goal: Test advanced UI components.

  • Selectable View: Use recipe "selectable_view" for a tabbed/gallery interface.
  • Grid: Use "parametric_grid" to build a sequence editor grid.
  • Target: #component-playground.

4. Mobile & Desktop Patterns

  • Mobile: Test bottom bars and FABs in #mobile-playground. Use emulate to see mobile views.
  • Dashboard: Build a 3-column stats row in #dashboard-playground.
  • Editor: Target #editor-playground to test complex multi-pane layouts.

5. Interaction & Feedback

  • Use simulate_event to "play" the keys or click the transport.
  • Use annotate to tag specific tracks or keys with AI notes.
  • Use interact to launch questionnaire slideshows.
